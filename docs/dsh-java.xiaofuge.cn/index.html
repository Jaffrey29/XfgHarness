Quickstart

两条命令，跑起来

「一键使用」单容器拉起 Harness 运行时；「插件安装」用标准部署包一键启动 Harness + MySQL 后台 + 商城，并预置两个插件。复制脚本即可开始。

1一键使用 · 启动运行时

单容器最小体验，打开 http://localhost:8090 即可进入控制台。

docker run -d \
  --name dsh-java-web \
  -p 8090:8090 \
  -e DEEPSEEK_API_KEY='your-model-api-key' \
  registry.cn-hangzhou.aliyuncs.com/xfg-studio/deepseek-harness-java:0.1.5

需要持久化数据、插件与配套案例时，请使用右侧标准部署包。

2插件安装 · 标准部署包

Compose 一键拉起三个服务，并安装/激活 dsh-java-mysql 与商城两个预置插件。

git clone https://github.com/fuzhengwei/dsh-java-deploy.git
cd dsh-java-deploy

cp .env.example .env
# 修改 MALL_SERVICE_TOKEN、DEEPSEEK_BASE_URL、DEEPSEEK_API_KEY

docker compose up -d
./scripts/install-plugins.sh

部署包已内置插件 JAR，无需先构建业务源码。

查看部署详解（含 MySQL 库表导入） 前往 GitHub 下载 dsh-java-deploy ↗
Runtime

单实例可运行，扩展即插即用

面向本地智能体工作台、企业内部扩展平台与任务自动化系统。当前定位是单实例运行时，而非分布式多租户 SaaS。

ReAct 循环

ReactLoopAgent 驱动模型输出、工具调用、结果回填与续步，单 turn 上限 50 步。

真实工具系统

内置文件、Shell、Web 搜索/抓取和用户提问工具；统一 ToolCallExecutor，并支持 PRE/POST Hook。

双模式插件

Java Native 使用 URLClassLoader 隔离，Node Bridge 使用 sidecar JSON-RPC，另支持 MCP stdio 工具。

权限与审批

提交期权限矩阵评估，高风险 Shell、写文件、插件和子进程默认进入人工审批。

事件溯源

会话、任务、目标、审批与模型设置落库；默认 MySQL，standalone profile 可切换 H2 文件库。

原生控制台

原生 JS 实现，本地化 Markdown、代码高亮与 XSS 净化，无前端构建链。

Use Cases

两个已验证的接入案例

它们不是演示草图，而是可以直接构建、安装插件并跑通工具调用的项目。

DATABASE

dsh-java-mysql

MySQL 管理后台 + AI 数据库助手。连接配置、表浏览、只读查询、执行计划、性能快照和 SQL 风险审计都可在本地闭环。

  • AI 链路全程只读，不提供写 SQL 工具
  • 注册 5 个 MySQL 查询与审计工具
  • 默认 15 秒超时，最多返回 500 行
  • 写操作必须控制台人工确认
查看 GitHub 仓库 →
MALL

2D Weekend Mall

PC 虚拟商城与智能客服插件。商品搜索、购物车、下单、支付、订单和物流跟踪在浏览器闭环，客服能力由 Harness 插件提供。

  • Spring Boot 提供商城 REST API
  • 注册商品、订单、物流查询插件工具
  • 通过服务凭证隔离用户订单查询
  • POST_TOOL_USE 发出客服审计事件

Community Plugins

开发插件，发布到社区

DSH Java 的能力边界由插件决定。为自己开发插件，或发布到 GitHub 与社区共享——只需一个标签，就会被社区收录。

1

开发插件

实现 SPI 契约并注册工具，支持 Java Native、Node Bridge 与 MCP stdio 三种模式。

2

本地验证

打包 JAR 后通过 /api/harness/plugins/install 安装激活，在控制台跑通工具调用。

3

发布到 GitHub

把插件源码推送到公开仓库，写好 README 与安装说明。

4

添加收录标签

给仓库添加 dsh-plugin-java 标签（topic），即会被社区插件列表自动收录。

# dsh-plugin-java

一个标签，进入社区插件生态

GitHub topic 是社区插件的统一收录入口。任何人为仓库添加 dsh-plugin-java 标签后，插件就会出现在社区主题页，被其他开发者发现、安装和使用。

浏览社区插件 插件开发教程
add-topic
# 方式一：仓库主页 About → Topics 添加 dsh-plugin-java

# 方式二：GitHub CLI 一行搞定
gh repo edit --add-topic dsh-plugin-java
Deploy

最简便的部署与体验路径

单容器适合最小体验；标准部署包一键拉起 Harness、MySQL 后台、商城，并预置两个插件。详细步骤与 MySQL 库表导入见 部署详解页，部署包下载：github.com/fuzhengwei/dsh-java-deploy

1启动 Harness

docker run -d \
  --name dsh-java-web \
  -p 8090:8090 \
  registry.cn-hangzhou.aliyuncs.com/xfg-studio/deepseek-harness-java:0.1.5

适合最快体验。若需要持久化数据、插件与工作区，请使用标准部署包。

2标准部署包

git clone https://github.com/fuzhengwei/dsh-java-deploy.git
cd dsh-java-deploy

cp .env.example .env
# 修改 MALL_SERVICE_TOKEN、
# DEEPSEEK_BASE_URL、DEEPSEEK_API_KEY

docker compose up -d
./scripts/install-plugins.sh

启动 Harness、MySQL 后台和商城，并安装/激活预置插件。

3验证服务

curl http://127.0.0.1:8090/api/harness/plugins

http://127.0.0.1:8090    # Harness
http://127.0.0.1:8091    # MySQL 后台
http://127.0.0.1:18080   # 商城

能看到 dsh-java-mysql-plugin 和 mall-weekend-assistant 即代表插件链路安装成功。
